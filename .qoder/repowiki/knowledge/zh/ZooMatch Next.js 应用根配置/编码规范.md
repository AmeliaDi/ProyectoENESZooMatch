- Node 与 Python 依赖分别通过 `package.json` 与 `requirements.txt` 声明，并在 `.gitignore` 中分别忽略 `node_modules/` 与 `__pycache__/`，保持双栈隔离。
- TypeScript 配置采用严格模式（`strict: true`、`noEmit: true`、`isolatedModules: true`）并通过 `paths.@/*` 提供源码路径别名。
- 测试文件统一放在 `src/**` 下并以 `.test.ts` 后缀命名，由 Vitest 自动发现执行。
- ESLint 通过 flat config 组合官方 next-vitals 与 typescript 规则，并忽略构建产物目录。
- 安全相关的全局 HTTP 头（CSP、COOP/COEP、Permissions-Policy、HSTS、X-Frame-Options）集中在 `next.config.ts` 中通过 `headers()` 钩子统一注入。
