Run `npm install` (Node ≥ 22.12), copy `.env.example` to `.env.local`, apply all SQL under `supabase/migrations/` plus `seed.sql` and `seed_v2.sql`, promote the first admin with `promote_admin.sql`, then `npm run dev`. Regenerating psychometric data requires a separate `pip install -r requirements.txt` and execution of the Python scripts under `scripts/` before the TS runtime can consume the generated `data/*.json` fixtures.
