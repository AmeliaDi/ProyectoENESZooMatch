Node >= 22.12.0 is required per `engines`. Typical commands: `npm run dev` (Next dev server), `npm run build` / `npm start`, `npm run lint`, `npm run typecheck` (`tsc --noEmit`), `npm run test` / `test:watch` (Vitest). The Supabase integration requires `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` environment variables; without them `isSupabaseConfigured()` returns false and the hero shows a 'Foundation ready' indicator instead of attempting a connection.
