The project follows the Next.js App Router layout under `src/app` (`layout.tsx` defines global metadata and imports Tailwind globals; `page.tsx` renders the single `FoundationHero` component). UI logic lives in `src/components/foundation-hero.tsx`, a client component built with Framer Motion and Tailwind CSS. Data access is abstracted behind `src/lib/supabase/client.ts` (browser) and `src/lib/supabase/server.ts` (server), both wrapping `@supabase/ssr`'s `createBrowserClient` / `createServerClient` and gated by environment validation from `src/lib/env.ts`. Shared TypeScript shapes for the archetype catalog live in `src/types/archetype.ts`. Build/runtime configuration is centralized in `next.config.ts` (enabling React Strict Mode and typed routes), `tsconfig.json`, `postcss.config.mjs`, and `eslint.config.mjs`; Python helper scripts under `scripts/` operate on JSON fixtures in `data/` to generate archetype datasets independently of the Node runtime.
